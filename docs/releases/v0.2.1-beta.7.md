# LAT 0.2.1-beta.7

2026-10-15 本地验收版，完成第三轮历史检索、架构浏览连续性与通用控件整理。分支为 `codex/history-navigation-beta7`，基于 beta.6 的稳定性和性能改进继续开发，所有提交与安装包保留本地，尚未推送 GitHub、创建 PR 或发布版本。

## 用户可见变化

- 历史页面改为每页 20 条短摘要，展开时才读取当前记录全文；新增关键词全文搜索、原文/译文语言、模型与来源组合筛选，以及当前筛选全部记录的 JSON/Markdown 导出。
- 历史默认保留 30 条与 64 MiB 内容，可选 10/30/50/100/200 条和 16/32/64/128 MiB。统计说明内容容量口径，缩减前确认，单条超限不会删除原有数据，保存失败后可以重试。
- 升级保留原有全文和元数据，首次打开不裁剪已超过新容量的旧记录；页面提示先导出，下一次成功保存或主动调整上限时再淘汰最旧完整记录。
- 连续翻译时，后续结果不覆盖先前保存失败的记录；划词历史只在事务成功后确认，并发重复请求共享写入且分别返回结果，失败后可以重发。
- 架构页面按模型保留层、模块、张量、参数视图、教学步骤与滚动位置，切页后恢复为暂停状态。结构发生变化会使旧选择失效，离开页面仍卸载轮询和动画。
- 连线布局测量按帧合并，活动高亮与几何计算分离；共享选项卡、提示条和空状态组件，保留方向键、Home/End 和焦点关联，移除架构页内部重复标题。

## 数据与兼容性

历史库 `lat.history` 升级为 IndexedDB v2，保留 `translations` 全文 store，新增摘要 store 与复合时间索引。迁移、写入和裁剪均使用事务，失败回滚；普通列表、统计和裁剪不加载全部正文。关键词检索逐条读取符合其他筛选条件的候选全文，导出会读取匹配的完整记录，详细行为与成本见 [第三轮设计](../design/history-navigation-round3.md)。

内容容量是完整记录 JSON 的 UTF-8 字节数，包含原文、提交文本、译文与元数据，不等于 WebView 物理磁盘占用。失败保存队列只保留在当前窗口内存，关闭应用前应完成重试或复制需要保留的译文。导航状态使用当前窗口 sessionStorage，最多记住八个模型；关闭应用后不保证恢复，损坏或不可用的存储不影响正常浏览。

旧版本应用显式请求历史库 v1，升级后不支持直接用旧版读取历史；本版支持完整导出，数据库降级和历史导入不在本轮范围内。模型文件、推理配置和会话鉴权继续沿用；本轮没有宣称真实模型推理提速比例。

## 统一验收

请使用 [LAT 统一验收清单](../acceptance/lat-acceptance-checklist.md)，当前版本共 56 项，涵盖第三轮新增项、前两轮回归、划词、长文、公式、GPU、退出与第三方接口。建议先检查 H（历史）、A（架构）和 U（通用控件），然后完成其他适用项目。

原六份清单的全部正文已合并到同文件的历史附录，保留 95 个已勾选项、85 个未勾选项、用户反馈和翻译样例。逐块 SHA-256 核对与合并前源文相同，仅统一文本换行符。旧文件路径只提供跳转，不再维护独立清单；历史勾选没有自动转为本版本通过。
