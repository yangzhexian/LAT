# LAT 0.2.1-beta.9

2026-10-27 本地验收版，依据 beta.8 的七条反馈更新，分支为 `codex/acceptance-beta9`。用户提交的 beta.8 勾选与反馈先保存为独立提交 `6f6916c`，再完整归档到 [统一验收清单](../acceptance/lat-acceptance-checklist.md)。本版仅保留本地提交和安装包，尚未推送 GitHub、创建 PR 或发布版本。

## 反馈对应修改

| beta.8 反馈 | beta.9 行为 | 重点复验 |
| --- | --- | --- |
| 搜索框左侧高亮裁切 | 历史滚动容器预留焦点轮廓空间，保持滚动条间距 | H01 |
| Markdown/JSON 导出无反应、不知保存位置 | 原生另存为对话框，写入成功后显示实际完整路径；取消、失败和重试均有反馈 | H02–H04 |

| 架构混乱、动画像幻灯片、重复层选项过多 | 统一网格和共享层结构，架构移除逐层选项；真实层号只用于参数查看，组件动画并行循环，说明改为手动选择 | A01、A04–A06 |
| 交换看板顺序、GPU 默认 | GPU 硬件排左并默认显示，模型推理排右，键盘顺序同步 | G01、G02 |

## 导出与兼容

桌面导出通过仅限主窗口调用的 `save_history_export` 命令完成，前端传递格式与完整内容，不传入目标路径；目标由用户在原生保存对话框选择。使用同目录独占临时文件完整写入 UTF-8 并同步后替换目标，写入或替换失败时清理临时文件，保留现有导出。导出按当前筛选读取全部匹配记录，不局限于当前页或摘要。浏览器开发模式仍使用下载列表，并明确提示保存位置由浏览器管理。

架构元数据、本地模型、历史数据库和翻译推理行为沿用 beta.8，没有新增前端或 Rust 依赖。连续动画只展示计算原理，不读取真实权重或激活值，也不声称真实模型正在执行高亮模块。公式和字体从本地资源加载，参数区的层号继续对应本地 GGUF 的独立张量。设计详见 [模型架构浏览](../design/model-architecture.md)。

本版仍以 [统一验收清单](../acceptance/lat-acceptance-checklist.md) 为唯一入口，beta.8 的 56 个已勾选项、3 个未勾选项、七条原始反馈与更早的全部历史附录均完整保留。旧版已通过项不自动标为本版通过；第三方接口待验收项沿用，使用时可检查。
