# LAT 0.2.1-beta.5

2026-10-13 本地验收版，完成第一轮模型生命周期、取消链路与网关会话改进。分支为 `codex/runtime-stability-beta5`，本版保留在本地，等待用户验收。

## 变化

- 同一模型的并发启动合并到一个实例，显式加载另一模型会正确切换；加载失败清理后可以重试，状态提供生命周期、错误与运行实例标识。
- 翻译期间的模型、目录和下载管理操作有统一冲突保护。退出时关闭任务准入，避免迟到请求重新启动模型。
- 模型传输在连接、响应头、首条输出和生成期间检查取消；流式和普通翻译请求断开都会取消对应任务。分别控制连接、首响应、流空闲和总时限。
- 网关使用协议版本 2 与实例握手，桌面自动生成管理密钥，第三方翻译使用独立 API Key；断点续译和取消按凭据归属隔离。
- 桌面退出在后台清理自己创建的 Windows 进程树，主动复用的外部网关不被关闭。网关异常断开时保留工作区并提示重新启用模型。
- OpenAI 兼容流式响应在每段通过校验后发送内容，避免整篇完成后才开始发送；实际 token 汇总包括分段和重试，缺少完整计数时保持未知。

## 配置变化

普通桌面用户无需输入管理密钥。手动启动 `python -m local_translator serve` 必须提供 `LAT_ADMIN_TOKEN` 或本地 `admin_token`；命令行状态、卸载和停止操作使用相同密钥。第三方客户端需配置 `LAT_API_KEY` / `api_key`，任意填写 `local` 不再有效；带 Origin 的额外浏览器来源需要明确配置 `allowed_origins`。

桌面复用手动网关时需在启动 Tauri 的环境中提供该网关的管理密钥，推荐使用至少 32 位随机字母、数字或 `-_.` 字符。管理密钥与第三方密钥应不同。前端开发模式使用同一管理密钥的 `VITE_GATEWAY_TOKEN`；只用于本机开发，不写入提交或分发包。

连接、首响应、流空闲与总时限默认分别为 3、120、30、600 秒，都是单次模型调用的限制。具体设置见 [README](../../README.md) 和 [运行时设计](../design/runtime-stability.md)。
