# LAT 0.2.0-beta.3

本预发布整合已通过用户验收的界面、长文本翻译与显卡监测更新。

## 新功能与改进

- 毛玻璃工作区、图标侧栏、模型启停动画和可访问的语言选择器。
- 默认支持 100,000 字符长文，分段翻译、实时进度、局部重试，以及取消/失败后继续剩余分段。
- 本地翻译历史，默认 30 条，可选 10/30/50/100/200 条，支持关闭保存、恢复、删除和清空。
- 显卡显存、利用率、功率及温度趋势图；应用启动后持续采样，支持 0.5/1/2/5 秒刷新和最近 1/2/5 分钟范围。
- 统一胶囊控件和减少动态效果设置，修正历史卡片高度及滚动条引起的布局跳动。

## 修复

- 修复 LaTeX 的成员符号、范数和 boldsymbol 显示。
- 修复 Hy-MT2 1.8B 提示词泄漏、内部尾标记残留、行内公式换序误判和长文中断。
- 保护公式、代码和 Markdown 链接目标，避免失败输出写入完整历史。

## 安装与说明

- Windows x64，当前模型运行环境面向 NVIDIA CUDA。退出旧版 LAT 后运行安装包；已有模型无需重新下载。
- 翻译内容留在本机。历史记录持久化；未完成任务断点保存在当前网关内存中，最多保留最近 8 个任务、闲置 1 小时后过期。
- GPU 指标为整卡数据；最近 5 分钟趋势仅保存在本次运行内存中，退出后清空。
- Beta 预发布，译文语义仍建议按使用场景核对。
