# LAT 0.2.1-beta.4

2026-10-02 本地复验构建，独立模型架构浏览，拆分推理/硬件看板并修复双滚动条。

## 更新

- 左侧新增“模型架构”，总览可以放大进入任意 Transformer 层及 Attention/KV、FFN、Embedding、Output 的细节，提供分步骤教学动画和返回导航。
- 架构尺寸、词表和各层张量形状来自本地 GGUF；不加载权重，不使用用户文本作为教学示例。动画可在模型空闲时演示，不表示逐层或逐参数遥测。
- 模型页使用“模型推理 / GPU 硬件”选项卡，默认推理；一次只展示一个看板，共享监测请求。
- 删除“真实计数”字样，保留来源及未知/部分统计提示。
- 模型与架构页采用外侧页面滚动，取消内部滚动条，长内容自然展开。

## 本地验证

Python 90 项、前端 31 项、Rust 23 项测试通过；1 项需要真实桌面鼠标的原生诊断默认忽略，本轮未运行。版本一致性、TypeScript、Rust 格式与编译、前端生产构建及 Windows NSIS 安装包构建通过。

本机已安装的 1.8B Q8_0 与 7B Q6_K GGUF 头部读取通过，两者均有 32 层、352 条层张量描述；分别读取 120,818 / 128,167 词表维度、128 head 维度与实际各层形状，未加载权重。

重新打包的网关在独立临时运行目录通过 health/version、初始空会话、新增未知架构字段及合成 GGUF header 的词表/head/首尾层张量解析。JSON/SSE `model_not_ready`、shutdown 与进程正常退出通过；未启动桌面或模型，也未执行真实推理测速。

使用真实工作区组件检查 1320 × 900 浅色和深色架构子页、900 × 560 短窗口中的推理与硬件选项卡、总览和 Attention 细节。模型与架构页没有内部滚动容器或水平溢出；任意层钻取、GQA 分组、Embedding/FFN/Output 步骤、标题定位、模型切换、关闭模型后浏览、减少动画及断联暂停通过。性能数值为标注的合成样例，不是实际推理测速或逐层性能遥测。
