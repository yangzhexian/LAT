# LAT 0.2.1-beta.1

本地验收版本，尚未发布到 GitHub，跨软件划词交互等待人工验收。

## 新增

- 选中文字后点击 LAT 浮标，或使用默认 `Ctrl+Alt+T` 快捷键进行本地翻译。
- 独立浮窗提供目标语言选择、原文折叠、LaTeX 预览、复制、固定及转到主窗口。
- UIA 优先取词；用户主动触发时可以按需使用复制兜底。剪贴板无法安全保护时提示手动复制。
- 托盘驻留与暂停划词、单实例唤回、划词历史来源标识。
- 浮窗翻译仅使用当前已启用模型；忙碌时保留文本供稍后重试。

## 安装与验收

- Windows x64，模型推理仍面向 NVIDIA CUDA。退出旧版后安装，已有模型与历史无需重新下载或迁移。
- 划词默认关闭；设置中首次启用会同时启用关闭到托盘。退出请使用托盘菜单，以释放模型显存。
- 浮窗直接翻译最多 5,000 个 Unicode 字符；更长内容完整转入主窗口，替换前确认。
- 重点验收 Chrome/Edge 网页及文本 PDF；图片和扫描 PDF 不包含 OCR，管理员窗口和自绘控件可能需要手动复制。
- [人工验收清单](../acceptance/lat-selection-translation-checklist.md)；[设计与调研](../design/selection-translation.md)。

安装包与 `SHA256SUMS.txt` 生成到本地 `artifacts/v0.2.1-beta.1/`，不提交 Git。验收完成并获得发布指令后再推送、提交 PR 和发布预发布版本。
