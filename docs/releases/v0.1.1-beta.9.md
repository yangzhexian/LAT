# LAT 0.1.1 Beta 9

## 主要变化

- 下载 Hy-MT2 GGUF 模型改为可折叠选项框：没有已安装模型时默认展开，有模型时默认收起。
- GPU 名称和总显存显示在所选模型的参数与显存说明小字中，正常状态不再显示独立环境提示框。
- 移除下载界面中的报告质量指标提示。
- 模型下载默认使用 hf-mirror.com，官方 Hugging Face 源作为回退源。
