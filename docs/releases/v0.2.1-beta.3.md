# LAT 0.2.1-beta.3

2026-10-02 本地复验构建，新增推理看板与模型架构路径动画，修复固定浮窗再次划词时移动的问题。

## 新增

- 模型硬件页新增输入、输出、总 token、生成/输入处理速度、首 token 延迟、耗时，以及本次网关会话的累计用量和有界调用历史。
- 长文分段与质量重试计入各次实际模型调用；未知用量明确区分，取消及异常不会继续显示活动状态。
- 从本地 GGUF 读取架构信息，提供交互模块说明、层堆叠和推理阶段光流；动画可暂停并遵守减少动态效果。
- 架构动画是计算路径示意，无法观测的逐层和逐参数活动不显示为实测。原文、译文及提示词不进入监测历史。

## 修复

固定翻译浮窗后再次划词保留用户拖动、调整后的窗口位置和尺寸；取消固定后恢复自动定位。
