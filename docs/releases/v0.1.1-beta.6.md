# LAT 0.1.1 Beta 6

这是从 Beta 1 升级而来的 Windows 预发布版本，运行后端已从 Ollama 完整迁移到由 LAT 管理的 llama.cpp。

## 主要变化

- 无需安装 Ollama；LAT 会下载并管理固定版本的 llama.cpp CUDA 运行时。
- 自动下载并校验 Tencent 官方 Hy-MT2-7B Q6_K 权重，主源失败时切换备用镜像。
- 下载支持断点续传、取消、重试、文件级进度和最终完整性确认。
- 翻译完成后保留 tokens/s、耗时和生成 token 数。
- 更新和卸载会终止后台进程，并询问是否删除模型与运行时数据。
- 前端和 Python 网关完成模块化整理，加入 Windows CI 与统一版本检查。

## 使用要求

- Windows 10 或更新版本。
- NVIDIA GPU 与可用的 NVIDIA 驱动。
- 建议总显存至少 10 GiB。
- 首次运行需要联网下载约 6.16 GB 模型和 llama.cpp CUDA 运行时。

## 升级提示

- Beta 1 的 Ollama 模型不会被新版本使用。
- 新版默认把数据保存在安装目录下的 .lat-runtime，也可以在开始界面选择其他目录。
- 如果保留旧版后台进程，请先退出旧版 LAT 再安装。
