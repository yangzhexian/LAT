# LAT 0.2.0 Beta 1

## 重要 feature

- 内置管理 Windows NVIDIA CUDA 版 llama.cpp，无需预装 Ollama。
- 首次启动支持下载 Hy-MT2 GGUF 模型，并提供断点续传、取消、重试、文件级进度、SHA-256 校验和备用镜像。
- 新增 NVIDIA GPU 总显存预检和模型推荐逻辑。
- 新增 Hy-MT2 1.8B 与 7B 的 Q4_K_M、Q6_K、Q8_0 版本，以及低资源量化版本。
- 模型下载默认使用 hf-mirror.com，官方 Hugging Face 源作为回退源。
- 模型选择页支持可折叠的模型选择和下载区域；已安装模型使用两列布局、蓝色状态圆点和颜色区分当前选择。
- 翻译完成后保留 tokens/s、耗时和生成 token 数，并统一使用最终 token 速率。
- 新增 Windows CI、版本一致性检查、安装包校验和 Beta 发布流程。

## 重要 fix

- 仅在全部文件校验通过后发送下载完成事件，主源失败时切换到校验值一致的备用镜像。
- 修复关闭应用、更新或卸载时 gateway 与 llama-server 进程残留。
- 支持 Ctrl+Enter 启动翻译，并兼容 CRLF 格式的 SSE 数据。
- 修复深色主题下文本编辑区和预览区滚动条样式问题，并移除重复的翻译指标显示。
- 修复 Hy-MT2 1.8B Q8_0 输出中的 [结束翻译] 尾标记未被清理的问题。
- 修复 Windows CI 在 Rust 检查前未生成 sidecar 导致 Tauri 构建失败的问题。
