# LAT 0.2.1-beta.6

2026-10-15 本地验收版，完成第二轮分段调度、遥测与长文界面性能改进。分支为 `codex/performance-beta6`，保留本地提交，尚未推送 GitHub、创建 PR 或发布版本。

## 用户可见变化

- 主窗口长文和划词翻译共用有界队列。长文在已校验分段之间让出推理机会，浮窗显示等待位置；取消浮窗仅取消自身请求，普通任务有公平调度保护。
- GPU 看板优先直接读取 NVML，持续保留最近五分钟历史；兼容回退采用实际两秒或五秒采集周期。GPU 增量、推理数据和架构分别请求，页面切换不重复传输全部张量信息。
- 明确单个推理槽位及批次、微批次、Flash Attention 和缓存配置，默认保留 `f16` KV 及原有质量检查；未实测宣称固定提速比例。
- 长文进度合并更新，文本面板复用；只有可见预览排版公式。LaTeX 最多预览 4,000 个 UTF-16 字符及 40 个完整公式，文本视图和历史保留全文。

## 配置与兼容性

普通桌面用户可继续使用默认配置。新增 `max_pending_translations=8`、`queue_wait_timeout_seconds=120`、`batch_size=2048`、`ubatch_size=512`、`flash_attention=auto`、`kv_cache_type=f16`、`cache_prompt=true`。本地 JSON 和环境变量说明见 [README](../../README.md)，实现和公平调度边界见 [第二轮设计](../design/performance-round2.md)。

旧组合遥测接口继续保留，新页面使用拆分接口。手动复用网关时需同时升级网关至 beta.6。当前分段不会被半途抢占，划词延迟仍取决于分段推理耗时；超时和取消可保留已完成分段。全文公式分页不在本轮范围内。
