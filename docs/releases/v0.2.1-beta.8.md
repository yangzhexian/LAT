# LAT 0.2.1-beta.8

2026-10-22 本地验收版，将模型架构总览中的重复层改为单层堆叠页面。分支为 `codex/architecture-stack-beta8`，基于 beta.7，继续沿用现有历史、翻译、遥测和导航记忆。本版保留本地提交与安装包，尚未推送 GitHub、创建 PR 或发布版本。

## 架构呈现

总览按“输入嵌入 → Transformer 堆叠页 → 输出”纵向排列。前页只显示当前所选一层的完整计算路径，包括归一化、Attention、两条残差和 FFN，背后最多两张装饰页与层数标记表示重复层。堆叠表达结构的相似性，各层参数仍独立，参数详情始终按实际层号读取。

层编号可以直接切换，选中最后一层也只替换前页内容；超过 128 层使用有界编号输入，不生成大量重复架构或选项。总览可直接进入 Attention/FFN，也可进入本层步骤与参数视图；Embedding、Output、面包屑和按模型记忆浏览位置继续可用，返回总览保留所选层。单层模型没有重复背页，未知层数不虚构第一层。

旧书架、蛇形层间连线与抽书定时器已移除。装饰背页不能成为键盘焦点，也不进入辅助技术读取顺序；明暗主题、减少动态效果、页面隐藏及断联暂停保持原有行为。连线按图限定端点作用域，防止外层总览误用内层同名端点，并继续合并布局测量；教学高亮不触发几何重测。实现与数据口径见 [架构设计](../design/model-architecture.md)。

## 验收与兼容

继续使用 [LAT 统一验收清单](../acceptance/lat-acceptance-checklist.md)，本版重点为 A01–A10，尤其 A08 的单层堆叠、A09 的层与参数对应、A10 的单层/未知层边界。当前共 59 项，历史附录中的 95 个已勾选项、85 个待验收项及用户反馈均未修改；旧归档不作为本版已通过记录。

模型权重、运行配置、历史数据库版本与导航存储结构均沿用 beta.7。本次修改不改变翻译质量校验或模型推理行为，也不声明实际模型提速。安装前从托盘退出旧 LAT，沿用原数据目录。
