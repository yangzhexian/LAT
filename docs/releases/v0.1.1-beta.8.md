# LAT 0.1.1 Beta 8

## 主要变化

- 修复深色主题下文本编辑区和预览区滚动条仍显示浅色的问题。
- 新增 Hy-MT2-1.8B 与 Hy-MT2-7B 的 Q4_K_M、Q6_K、Q8_0 选择，并提供 1.8B 2-bit 与 1.25-bit 低资源版本。
- 下载界面展示模型文件大小、建议总显存和报告 benchmark 摘要。
- 环境预检改为只依据 GPU 总显存，并在可用版本中推荐质量排序最高的模型。
- 多模型下载、SHA-256 校验、启动和已安装模型状态保持一致。
- 移除翻译完成后右上角重复显示的 token 数，最终速度、耗时和 token 数继续保留在左下角。
- 正式重写 GitHub README，补充模型选择、构建、数据目录和故障排查说明。

## 模型推荐说明

推荐逻辑采用包含 llama.cpp 缓冲区和常用上下文预留的保守总显存阈值。Hy-MT2 技术报告没有分别评测 Q6_K 和 Q8_0，因此这两个版本仅作为同一参数规模下的高精度部署选项展示。
