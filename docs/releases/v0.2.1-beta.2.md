# LAT 0.2.1-beta.2

根据 beta.1 用户验收反馈修复划词交互。本版为本地复验构建。

## 修复

- 鼠标监听线程按消息唤醒，移除固定休眠；同步窗口查询移到工作线程，避免取词拖慢鼠标输入。
- 原生鼠标按下/抬起直接激活浮标，解决首次点击无响应；网页物理点击不再重复发起请求。
- 新输入使等待中的旧取词结果失效；快捷键在处理时分配请求编号，避免排在前面的旧鼠标事件取消新请求。
- 翻译浮窗使用 Windows 系统圆角，移除窗口内额外的外层圆角和边框。

## 安装与复验

- Windows x64；安装前通过托盘“退出”真正结束旧版 LAT，已有模型、历史与设置继续沿用。
- 重点复验冷启动后的首次浮标点击、持续启用后的鼠标响应和浮标、不同主题及 DPI 下的系统圆角。
- beta.1 用户已填写的验收勾选与反馈保留；复制兜底尚未覆盖，继续按清单补测。
- [验收清单](../acceptance/lat-selection-translation-checklist.md)；[技术设计](../design/selection-translation.md)。
