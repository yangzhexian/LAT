## 剪贴板和焦点保护

以下项目须覆盖真正触发复制兜底的场景。UIA 已成功取得文字时不应修改剪贴板；若当前测试软件一直使用 UIA，可在反馈中注明兜底尚未覆盖，不直接勾选为通过。

- [ ] 剪贴板预存普通文本，使用 UIA 取词后，原剪贴板保持不变。
- [ ] 剪贴板预存普通文本，执行复制兜底后能恢复原内容；原始选择文字及译文正确。
- [ ] 剪贴板预存带 HTML/RTF 格式的文字，兜底后格式和内容完整恢复，或在操作前明确拒绝无法安全备份的格式，不悄悄降级为纯文本。
- [ ] 剪贴板预存图片，兜底后图片完整恢复，或安全拒绝兜底；图片不丢失、不被文本覆盖。
- [ ] 剪贴板预存文件列表，兜底后文件列表完整恢复，或安全拒绝兜底；仍能正常粘贴文件。
- [ ] 目标应用不响应复制时，提示未取得选区，不以备份中的旧文本发起翻译。
- [ ] 兜底期间在其他应用执行新的复制，LAT 不恢复旧备份覆盖新内容，也不把另一窗口的新内容翻译为本次选区。
- [ ] 点击浮标前切换应用，或触发快捷键后立即切换焦点，不会向错误窗口发送复制或翻译错误窗口内容。
- [ ] 按住快捷键再松开时，不粘连 Ctrl/Alt 修饰键；后续输入和快捷键正常。
- [ ] 关闭复制兜底设置后，UIA 失败会明确提示，不再模拟复制；用户剪贴板保持不变。

## 浮窗、模型和任务隔离

- [ ] 浮窗默认自动识别原文并译为中文，目标语言独立记忆；修改它不改变主窗口语言。
- [ ] 原文折叠、译文复制、重试、文本/LaTeX 预览均正常；没有 prompt 或内部保护标记泄漏。
- [ ] 未固定时失焦关闭；固定后切换应用仍显示；关闭操作可用。
- [ ] 浅色/深色主题和减少动态效果与主窗口一致，窗口缩放后内容可读、按钮仍可操作。
- [ ] 100% / 150% / 200% 缩放下，浮标和浮窗不越过当前显示器工作区；多显示器之间移动后位置仍正确。
- [ ] 模型未启用时保留取词内容并提示前往启用，不自动加载或下载；在主窗口启用后可回到浮窗重试。
- [ ] 主窗口长文正在翻译时触发划词，浮窗提示忙碌及重试，原任务持续执行，不被取消或排队抢占。
- [ ] 浮窗正在翻译时再次划词或按快捷键，当前任务和原文不被新内容覆盖。
- [ ] 关闭正在翻译的浮窗只取消它自己的任务；马上重新取词时不混入上一请求的迟到输出。
- [ ] 浮窗关闭或取消后，主窗口可以继续发起翻译；正在完成取消时的短暂忙碌提示可理解且可重试。
- [ ] 翻译期间手动关闭模型后出现可操作错误，不重新自动加载模型，不误报翻译成功。
- [ ] 含恰好 5,000 个 Unicode 字符的选区可在浮窗发起；5,001 个字符提示转到主窗口，没有截断。
- [ ] 超长选区转到主窗口后保留全文；主窗口已有草稿时先确认，取消替换会保留原草稿。

- [ ] 关闭“关闭到托盘”后关闭主窗口，应用正常退出；托盘“退出”也会真正退出。
