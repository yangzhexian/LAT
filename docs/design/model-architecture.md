# LAT 模型架构浏览（0.2.1-beta.9）

左侧“模型架构”独立入口与“模型”监测页分开。未启用模型时也可以读取已安装 GGUF 的架构；查看架构不会启动 llama-server 或执行额外推理。缺少本地模型、旧网关或读取失败时显示相应状态，不伪造层数或维度。

## 逐级查看

- 总览采用统一网格的连续画布，展示输入嵌入、Transformer 堆叠页和输出路径。相似的重复结构只绘制一份共享架构，背后最多两张装饰页与层数标记表达整个层组，不为每个真实层创建重复 DOM 或架构选项。各层仍具有独立参数，真实层编号仅在画布下方参数检查区使用。
- Transformer 层展示归一化、Attention、残差与 FFN 路径；输入分出第一条残差接回 Attention 后的加法节点，该节点再分出第二条残差接回 FFN 后的加法节点。主路、旁路及输入/输出端口连续可见，可以继续进入注意力或前馈细节；查看共同计算关系无需选择具体层。
- Attention 展示 Q/K/V、查询头与 KV 头的分组关系，以及每层 KV cache 的读写示意。
- FFN 展示隐藏表示的扩展、激活/门控与投影返回；Dense 路径只在确认支持的架构上使用，缺失的激活配置不编造名称。
- Embedding 用占位 token 演示查表获得隐藏向量；Output 用示例词表分数演示 logits、概率与采样。

连线路径、矩阵单元、缓存槽位和输出条形使用独立循环的 CSS 动画，同时表达计算关系；不再通过定时切换步骤来驱动整个画布。模块说明由用户手动选择，暂停动画不会隐藏结构，开启减少动态效果时仍可阅读所有内容。动画、token、向量、概率和矩阵纹理是教学示例，不是用户提示词、实际权重、真实注意力分数或采样结果，不代表运行模型正在执行某层。

向量集合、注意力、门控、嵌入查表和输出投影等表达式使用现有本地 MathJax 上下文进行 LaTeX 排版。公式组件按 TeX 内容缓存，动画和手动高亮不反复排版；独立表达式转换在引擎就绪、启动完成及结果返回时检查组件是否仍有效，只有当前节点可接收结果，快速切页不会将空节点传给排版引擎。转换后更新本地 CHTML 样式表，再通知当前图和外层图按帧合并重测，防止首次字体样式缺失或公式高度变化造成连线错位。方向图标显式限定宽高，打开入口不再使用多余的右上箭头，图形连线继续保留必要的流向。

参数区使用有界数字输入选择实际层编号，默认使用矩阵视图，按 Q/K/V/O、FFN 和归一化等用途选择张量，展示其 GGUF 原生存储轴、元素数量，以及占本层已读取元素的比例。一维归一化参数显示向量，不乘以 head 数；二维或高阶张量使用有界分块示意，不按元素数量创建 DOM。格子颜色不编码实际权重、正负或活跃状态；高阶张量同时列出其他存储轴。

“矩阵视图 / 张量列表”可用鼠标和方向键切换，列表保留原始名称及形状。占比分母仅包含本层返回的已知元素数量；未知数量和截断列表明确提示。该占比不是显存占比，模型整体量化名称也不作为每个张量的精度。

## 数据与边界

架构通过 `/admin/architecture` 获取并使用 ETag 条件请求，兼容的组合遥测接口继续保留。元数据包含可选 `vocab_size`、`head_dim`、`block_tensors` 和 `block_tensors_truncated`。每个张量描述包含 1-based `layer`、名称、GGUF 存储维度 `shape` 与元素数量 `elements`。维度顺序保留 GGUF 原始顺序，不当成普通矩阵的行列顺序。元素数不是实际激活数或运行时 FLOPs。

词表大小来自嵌入张量形状或元数据；head 维度优先读取 `attention.key_length`，仅对已确认的 `hunyuan-dense` 在可整除时由隐藏维度与查询头数推导。每层张量列表以本地 GGUF 描述为准，不假设所有层的存储形状必定相同。

只读取有界 header、metadata 和 tensor descriptor，最多保留 4096 个层张量描述；超过时标记截断。参数总量仍统计整个有界文件头中的张量。缓存按模型、路径、大小与修改时间失效，返回值深拷贝避免共享嵌套形状被改动；不读取权重数据、词表内容或用户翻译文本。

模型与架构页统一采用外侧页面滚动，内部内容自然展开。主动进入子页后聚焦新标题并定位到细节，通过参数区层编号输入切层时保留控件焦点，轮询更新不会抢走滚动位置。动画遵守暂停、页面隐藏、断联、应用和系统减少动态效果；不靠颜色或动画单独表达模块含义。键盘可操作入口、参数层选择、模块说明与播放控制。

总览始终只绘制一份共享层架构，单层模型不显示重复背页；层数未知或无效时不虚构第一层或参数入口。较大层数通过参数区编号输入访问，层数增长不会增加架构页数或选项数量。查询头最多绘制 128 个按钮，超出时可输入真实编号；张量描述达到 4096 条上限时提示列表截断，不将缺失详情误报为缺少模型结构。

堆叠页仅表达结构的相似性，不声称所有层的张量形状或参数值相同。总览可以直接进入 Attention/FFN，参数层号与模块视图分别保留。装饰背页不可聚焦且不进入辅助技术读取顺序；没有等待抽书完成的交互延迟。导航记忆沿用 beta.7 的会话存储与结构签名，其中层号表示参数检查目标，步骤字段表示手动选择的说明；切页返回后暂停播放。
