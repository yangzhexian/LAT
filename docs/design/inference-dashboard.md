# LAT 推理看板（0.2.1-beta.4）

## 数据与展示

模型页通过“模型推理 / GPU 硬件”选项卡切换 LAT 模型调用指标与 NVIDIA 整卡趋势，默认显示推理；按钮共享同一轮询，切换不增加请求。整卡显存、功率、温度和 GPU 利用率仍包含其他程序的占用；推理用量来自通过 LAT 网关发出的模型调用，不将整卡负载当作模型专属负载。“真实计数”文案已移除，来源和统计不完整状态保留。

`GET /admin/telemetry` 保留原有 GPU 字段，新增 `inference`，包含活动调用、最近调用、有界调用历史、当前网关会话累计及模型架构。数据只保存在内存，网关退出后清空；不记录原文、译文、提示词或页面 URL。查看看板不会启动模型或额外发起生成请求。

| 指标 | 口径 |
| --- | --- |
| 输入 token | llama.cpp 报告的 prompt token 用量，包含翻译提示词 |
| 生成 token | llama.cpp 报告的 completion token 数，不能用 SSE chunk 数替代 |
| 总 token | 同一调用已知的输入与输出用量；缺失任何一项时标记未知 |
| 生成速度 | 使用 llama.cpp 解码计时；缺少计数或计时则未知，不用文本片段估算速度 |
| 输入处理速度 | llama.cpp 的 prompt 处理速度；缓存命中时不能把完整输入长度除以部分处理时间 |
| 首 token 延迟 | 从模型调用开始到首个非空文本输出到达网关，包含调度、输入处理和通信 |
| 调用耗时 | 网关观测的模型调用耗时 |
| 会话累计 | 累加已结束调用报告的用量；调用次数包含进行中调用。用量未知的调用数单独报告，不将未知调用伪装成零消耗 |

长文分段和质量重试均产生独立模型调用。已经调用模型但被质量检查拒绝的输出也消耗 token，必须计入累计；复用已校验译文的缓存段不产生新调用。取消或异常时保留已报告用量并标记结束状态，尚未收到的统计保持未知。统计不完整时，会话总量只累计已知部分并标明下限。历史最多保留 120 次调用，图表展示最近 24 次，不保留全文。

## 架构与动画

架构来自当前选中本地 GGUF 的 metadata 和张量形状，读取 header 时有大小、数量及类型边界并缓存结果，不读取权重数据或执行模型。展示层数、隐藏维度、注意力头数、KV 头数、前馈维度、训练上下文长度、量化及存储参数数等可获得字段；缺失或读取失败时显示未知，不从模型名称编造数值。训练上下文容量不等于当前 LAT 的运行上下文设置。推理调用仍标注实际运行模型，独立架构页说明当前所选模型的结构；教学播放位置与该调用的运行阶段没有绑定。

架构剖面已从监测页独立为左侧“模型架构”入口。总览、逐层查看和分步骤教学动画见 [模型架构浏览设计](model-architecture.md)。共享权重按 GGUF 中存储的张量元素统计，可能与模型标称规模不同。

推理看板的阶段按请求生命周期和文本输出推断，等待首 token 不等于正在执行某一层。独立架构页的教学动画可以在模型空闲时播放，不作为推理阶段遥测。不展示伪造的逐参数热度、Attention 权重、MoE 专家路由或逐层执行进度。

监测断联时保留上次观测并标注状态待确认。隐藏页面时停止前端轮询并取消请求，退出页面时清理轮询。模型页按内容自然高度展开，使用外侧文档滚动；硬件图表和推理看板不再形成内部滚动容器。

## 固定浮窗

`selection::publish` 在更新选区时核对固定状态。固定时继续更新内容、显示及聚焦，但跳过包含定位和按显示器缩放尺寸的步骤，从而保留用户选择的位置和尺寸。取消固定后再次取词恢复跟随新选区；首次打开、未固定浮窗仍限制在选区所在显示器的工作区。
