# 第一轮运行时稳定性设计

对应版本：`0.2.1-beta.5`。本轮覆盖模型生命周期、取消传输、网关会话及桌面进程归属，继续使用单模型、单翻译任务的执行方式。优先级队列、GPU 采集器替换、推理参数调优和大文本前端渲染优化留在后续轮次。

## 模型生命周期

`LlamaCppProcessManager` 使用同一操作锁管理启动、显式切换、目录变更和停止。并发 `ensure_server()` 复用同一成功启动的实例；显式 `load_model()` 切换到请求模型，下载模型的选择状态不会隐式替换正在运行的模型。停止操作先递增代数并设置停止信号，再等待锁，启动中的旧操作会终止自身。

`GET /admin/status` 的 `lifecycle` 为 `unloaded`、`loading`、`ready`、`unloading` 或 `failed`，同时提供 `lifecycle_error` 和 `runtime_instance_id`。加载失败清理进程引用后可重新尝试；停止失败保留进程引用与错误，不把未退出的进程报告为已清理。相同数据目录的重复设置直接返回状态，避免启动界面重复提交目录时卸载模型。

翻译引擎的管理入口与翻译共用互斥锁。翻译进行中，加载、卸载、切换、下载和目录修改被拒绝，管理冲突返回 `model_busy`。网关退出会关闭新任务入口、取消活动任务，再停止模型；即使请求在退出前已通过 HTTP 鉴权，尚未开始的任务也不会重新启动模型。

## 取消与超时

模型流式传输使用本机 HTTP socket、自有字节缓冲和 100 ms 的可中断等待，支持普通响应及 HTTP chunked framing，保留跨网络块的 UTF-8 字节和 SSE 行。每次连接、发送和读取等待都检查取消信号，不依赖下一条模型 token 来结束阻塞。响应头及事件大小受限，提前 EOF 或不完整响应作为错误处理。

| 时限 | 默认值 | 口径 |
| --- | --- | --- |
| 连接 | 3 秒 | 建立模型 HTTP 连接 |
| 首响应 | 120 秒 | 从单次模型调用开始到首条 SSE 数据；仅心跳不算首条数据 |
| 流空闲 | 30 秒 | 开始响应后连续没有网络数据 |
| 总时限 | 600 秒 | 单次模型调用，包含连接和首响应等待；不是整篇文档时限 |

HTTP SSE 请求通过有界队列交接引擎事件，并发送心跳探测失联客户端。普通 JSON 请求也监测连接关闭。任一客户端断连仅设置自身请求的取消信号，模型连接在生成器退出时关闭；已完成的段落继续保存在网关的内存断点中。`/translate/cancel` 按任务 ID 和调用凭据归属匹配，不能取消其他密钥创建的任务。

模型健康探测和操作系统进程清理仍有各自的短时限，100 ms 是传输轮询间隔，不是对实际 GPU 取消、显存回收或重新就绪时间的承诺。真实设备表现由验收记录补充。

## 网关协议与权限

`GET /health` 返回服务名、应用版本、`protocol_version: 2` 和 `instance_id`，不返回密钥。桌面检查服务名、协议版本及当前会话实例；不兼容的旧网关或端口上的其他服务不能被当成可用模型后端。

Tauri 启动 sidecar 时生成随机管理密钥及实例 ID，经子进程环境传递。主窗口与翻译浮窗可以通过原生命令取得会话；划词浮标不能取得，只有主窗口可以管理网关启动和停止。前端仅在当前模块内缓存会话，不写入 IndexedDB 或 localStorage；401、进程错误或终止会使对应缓存失效，迟到的会话读取不能覆盖失效状态。已发出的变更请求不会因为鉴权失败自动重放。开发前端的 `VITE_GATEWAY_TOKEN` 仅在开发模式读取，生产构建通过静态分支剔除。

手动启动网关需配置 `LAT_ADMIN_TOKEN` 或本地 `admin_token`。第三方客户端使用独立的 `LAT_API_KEY` 或 `api_key`，可以访问翻译和模型列表，不能访问 `/admin/*`。两种凭据均使用 `Authorization: Bearer <key>`，应使用不同的随机值。默认只允许 Tauri、当前网关页面和本地开发前端的 Origin，额外浏览器来源使用明确的 `allowed_origins` 列表。

若桌面发现协议兼容的外部网关，只有运行环境提供正确管理密钥时才复用，标记 `owned: false`。本轮没有创建常驻系统服务、磁盘明文会话文件或自动共享管理员凭据。

## 进程归属与断联恢复

桌面持有自己启动的 gateway 子进程和 Windows Job Object，后者开启 `KILL_ON_JOB_CLOSE`，约束该 gateway 及其模型后代进程的生命周期。退出时先停止划词服务，在后台请求对应实例带鉴权的 shutdown，等待正常结束，超时再终止自己持有的子进程；最后释放 Job Object 清理残留后代。等待期间不阻塞 Tauri 主事件循环。

复用的外部网关不进入该清理路径，退出桌面不会向它发送 shutdown。协议与实例匹配也参与关闭判断，避免端口已被另一实例使用时向错误对象发送关闭请求。这一归属规则指桌面运行与退出路径；安装器既有升级/卸载流程不在本轮改造范围。

网关异常断开后，主窗口将模型标记为未就绪并保留工作区原文和已显示译文，重新启用模型会重新建立会话。网关内存断点、遥测会话及未持久化的任务不会跨进程重启恢复；需要新建翻译时仍可使用保留的原文。历史数据继续使用原有 IndexedDB。

## OpenAI 兼容输出与用量

`stream: true` 共用经过质量与格式保护的分段引擎。响应依次发送 assistant 角色、通过校验的译文段、结束原因；请求 `stream_options.include_usage` 时追加最终用量，然后 `[DONE]`。续译时先发送断点中已有的权威译文，再发送新段落；单个请求内不重复追加旧段。

输出粒度是已校验分段，短文本可能只有一个内容增量。未经验证的中间 token、提示词和失败尝试不会作为译文发送。错误或取消以带错误码的 SSE 错误结束，不能作为完整翻译保存。

`prompt_tokens`、`completion_tokens` 和 `total_tokens` 汇总同一任务实际发生的模型调用，包括失败质量重试、运行时细分和续译；重复段缓存不再次计数。如果中途断开或上游未提供完整计数，对应统计保持未知，非流式响应省略 `usage`，流式最终用量返回 `null`。无需调用模型的纯受保护内容可以具有真实的零调用计数。

## 验证与边界

自动测试覆盖并发启动、模型切换、启动失败恢复、加载期间停止、退出时任务准入、两种响应的断连取消、等待响应头及首条输出时取消、空闲/总时限、分块 UTF-8、权限与 Origin、增量输出时机、未知用量和会话失效竞态。原有长文、LaTeX、提示词后处理、划词浮窗、架构浏览和硬件历史测试继续执行。

开发过程不驱动实际桌面、鼠标或剪贴板，不自动安装或运行 LAT，不加载模型进行压测。真实 GPU 推理、Windows 退出行为和第三方客户端兼容性在 [验收清单](../acceptance/lat-runtime-stability-checklist.md) 中由用户确认。
