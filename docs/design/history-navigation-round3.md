# 第三轮：历史检索、架构浏览连续性与通用控件

适用版本：`0.2.1-beta.7`。本轮沿用 beta.5 的运行时与鉴权、beta.6 的分段调度和遥测，重点缩小历史页面的常驻数据规模、保留架构浏览位置，并统一已有页面的控件行为。实现无需新前端依赖，翻译内容继续保存在本机。

## 历史存储与数据完整性

`lat.history` 升级为 IndexedDB v2，保留原有 `translations` 全文 store，新增 `summaries` store 及 `[createdAt, id]` 复合时间索引。升级在单个事务中逐条为旧记录建立摘要，不删除原库，不重写全文与额外元数据；失败回滚。每个连接在事务结束后关闭，收到 `versionchange` 时主动释放，升级被旧窗口阻塞时提示重试，迟到的成功连接也会关闭。

摘要包含 ID、时间、模型、语言、来源、逻辑内容字节数，以及各最多 160 个 Unicode 码点的原文/译文预览。普通列表每页 20 条，使用时间和 ID 的稳定倒序游标，不把全部全文载入 React 状态。仅当前展开记录读取完整内容，收起或切页后卸载全文 DOM。统计和容量裁剪只遍历摘要。`readHistory()` 保留为兼容接口，工作区不再调用它读取列表。

全文关键词搜索先应用模型、语言和来源筛选，再逐条读取候选记录检查原文、提交文本与译文；输入防抖 250 毫秒，过期异步结果不能覆盖最新筛选。当前最多 200 条记录，暂不维护额外全文索引，关键词搜索和导出仍有读取全文的成本。导出当前筛选下所有完整记录，不限于当前页；JSON 保留全部字段，Markdown 保留原文、译文和主要元数据，以动态长度代码围栏保护原有 Markdown 文本。

默认条数为 30、内容容量为 64 MiB，可选择 10/30/50/100/200 条与 16/32/64/128 MiB。容量口径是完整记录 JSON 的 UTF-8 字节数，包含 `source`、`submittedText`、`translation` 和元数据，不包含摘要副本、索引及 IndexedDB 的实际磁盘开销。新写入和裁剪处于同一事务，达到任一上限时保留最新记录并删除最旧完整记录。单条超限在开事务前拒绝，避免为无法存入的新记录删除原有数据。首次挂载只读取统计，保留旧版已超出新容量的记录；超限页面显示提示，下一次成功新增或主动改变上限时才应用限制。设置缩减会先提示删除旧记录的后果，快速连续更改会在当前事务结束后按最新偏好补做裁剪。

主窗口保存失败保留全文并提供重试入口，待保存项按 ID 去重排队，后续翻译成功或失败都不会覆盖前一条失败记录，重试成功只移除对应项。该队列位于当前窗口内存，退出应用不持久化，界面提示关闭前重试。划词记录在事务提交成功后才计入完成去重集合，并发相同记录共享一次写入，但每个请求都获得对应确认；失败可以再次发送。ID 主键提供跨进程重开后的幂等写入，同一窗口的短期去重集合只作为辅助。数据库异常、容量错误与导出失败都有可见反馈，自动测试覆盖回滚和重试。

v2 保留了原始全文 store，但旧版本应用显式请求 v1，升级后不支持直接用旧版读取历史。本版可导出 JSON/Markdown；数据库降级或历史导入不在本轮范围内。

## 架构浏览状态

架构页仍在离开后卸载，避免保留隐藏页面的轮询或动画。导航状态放入本窗口 `sessionStorage`，按模型保存并限制最近八个模型，只记录层、模块、选中张量、参数视图、教学步骤与滚动位置，不保存翻译内容或模型权重。恢复时校验状态字段、层和张量范围，并以结构签名隔离不同模型及元数据变化；结构失效时回到总览。

同一会话切页返回会恢复浏览位置，教学动画默认暂停；用户主动播放后才继续。关闭应用后不保证保留会话导航。存储被禁用或损坏时回到安全默认状态，不阻断架构查看。实际外层滚动容器由可滚动祖先或文档确定，恢复选择与视图后再设置滚动偏移。架构内部不再重复显示页面主标题，保留模型标识与导航路径。

连线几何与活动高亮分离。尺寸变化、窗口 resize 和字体加载通知共用单次 `requestAnimationFrame` 测量，容器和端点边界每帧各读取一次。教学步骤或播放高亮更新仅修改样式，不重新读取布局；卸载时取消待执行帧并移除观察与事件监听。

## 通用组件与验收入口

`Controls` 提供共享 `Tabs`、`Notice` 和 `EmptyState`，延续已有 Button、DangerButton、Switch、OptionGroup 和 SelectField。看板选项卡使用 roving tabindex，支持左右方向键、Home/End，并保持面板关联；错误提示使用 alert，普通状态使用 status。历史与架构复用同一组提示和空状态样式。

验收只维护 [统一清单](../acceptance/lat-acceptance-checklist.md)。其当前项目覆盖本轮新增功能、第一轮稳定性、第二轮性能及原有功能；六份旧清单的正文、勾选、反馈和样例原样放入同文件历史附录，旧路径仅保留跳转说明。历史结果不自动转为新版本通过状态，实际桌面体验、真实模型速度与安装升级由用户验收。
